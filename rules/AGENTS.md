# Universal Coding AI Agent Rules: Design UX Ultra Engine

This file guides all autonomous coding AI agents (Antigravity, Claude Code, OpenAI Codex, Cursor, GitHub Copilot, Windsurf) when creating or modifying any frontend code, user interfaces, or design systems.

---

## Autonomous Agent Mandates

When asked to build, modify, or enhance any web interface, landing page, component, or application frontend:

### 1. Zero Generic UI ("No Vibe-Coded Slop" Directive)
- **Never produce generic Bootstrap/default Tailwind mockups** with flat gray boxes, lifeless 12px rounded cards, or unstyled system buttons.
- **Never use generic fake placeholder vibes**: Replace toy designs with authentic domain data (real SaaS metrics, actual B2B tiered pricing, genuine checkout flows, deep developer terminal logs).
- Infuse every design with the **Design UX Ultra 5-Pillar DNA**:
  - Dribbble visual richness (aurora glows, frosted glassmorphism, bento grids, subtle gradients).
  - Webflow kinetic interactions (spring transitions, smooth reveals, magnetic buttons, fluid clamp typography).
  - Bootstrap 5 responsive layout engineering (12-column flex containers, offcanvas drawers, floating labels, `--bs-*` tokens).
  - Mockplus UX heuristics (Fitts's Law CTAs, Hick's Law grouping, clear feedback states, skeletons, WCAG AA contrast).
  - Figma Community token architecture (3-tier tokens, 8pt spacing grid, 6-state variant matrices).

### 2. Total Domain Redesign Protocol
When a user asks to **redesign** a website:
- **Do NOT make minor superficial tweaks**. Completely transform the page architecture:
  1. Extract the user's authentic domain entities (products, metrics, users, transactions).
  2. Map them to archetypes from the **1,425+ Figma Community & Bootstrap Templates Catalog** (`templates/registry/templates-catalog.json`).
  3. Rebuild the visual hierarchy from the ground up: establish a high-impact hero, asymmetric bento showcase, social proof, interactive pricing calculator, and fluid clamp typography.
  4. Ensure the resulting site looks like an authentic, high-budget, bespoke product custom-crafted by a principal design studio.

### 3. Mandatory Structural Layout (Landing Pages & Websites)
Every standard landing page or website built with this skill MUST include:
1. **Floating Island Glassmorphic Header** with brand logo, anchored section links, and prominent CTA.
2. **High-Impact Hero** with an animated eyebrow pill badge, bold gradient-accented H1, concise value subtitle, dual CTAs, and an interactive UI preview or Bento hero widget.
3. **Credibility Proof Bar** with recognizable partner/client logos (monochrome with hover opacity).
4. **Asymmetrical Bento Feature Grid** combining 1 primary interactive card, 2 secondary metric cards, and feature highlights.
5. **Interactive Deep-Dive Section** (tabs, timeline cards, or scrollytelling).
6. **Social Proof & Metrics** with bold numbers and genuine customer quotes.
7. **Transparent Pricing / Value Calculator** with monthly/annual discount toggle.
8. **Interactive FAQ Accordion** with smooth spring expansion.
9. **Final Conversion Anchor Banner** with aurora background glow and risk-reversal guarantee.
10. **Rich Multi-Column Footer** with category links, status indicator, and copyright.

### 4. Motion & Tactility Standards
- Hover states must feel physically responsive:
  - Cards: `transform: translateY(-2px)`, subtle border brightening, soft glow shadow.
  - Buttons: `active:scale-[0.98]`, subtle shimmer highlight on hover.
  - Links: smooth underline expansion from center or left-to-right.
- Transitions must use custom spring or cubic-bezier curves (e.g. `cubic-bezier(0.16, 1, 0.3, 1)`), NEVER harsh linear transitions.

### 5. Technical Quality & Responsiveness
- Use semantic HTML tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- Ensure contrast ratio meets WCAG 2.2 AA (minimum 4.5:1 for body copy).
- Tap targets on mobile must be minimum 44x44px.
- Test mentally across 375px (mobile), 768px (tablet), and 1280px+ (desktop).
