# Claude Code Instructions: Design UX Ultra Skill

When Claude Code is asked to build, polish, or rewrite any user interface, webpage, landing page, or frontend component in this project:

- Follow the 5-step workflow defined in `SKILL.md`:
  1. Archetype diagnosis (SaaS, Agency, E-commerce, Enterprise).
  2. Establish semantic tokens from `templates/design-tokens/tokens.json`.
  3. Wireframe information architecture with Z-pattern or F-pattern.
  4. Inject Webflow kinetic interactions and Dribbble visual polish.
  5. Audit accessibility against WCAG AA heuristics.

- For quick scaffolding, refer to:
  - `templates/heroes/`
  - `templates/features/`
  - `templates/navigation/`
  - `templates/dashboards/`
  - `templates/components/`
  - `templates/landing-pages/`

- Never use arbitrary inline styles or flat uninspired gray boxes. Make every interface tactile, spatial, and delightful.
